### Key Audit Findings Highlight:
1. **Baseline Evaluation Protocol Flaw (P0 - Publication Blocker):** The reported 0.8548 accuracy for ST-GAT in `baseline_results.csv` and `metrics.json` was generated by evaluating a single fold checkpoint (`best_model.pt`) on its **training data** (all 2,589 samples across 30 subjects). In addition, `Wrist` and `Hand` landmarks for both left and right arms are mapped to identical MediaPipe points, forcing Wrist-to-Hand bone length to zero ($0.0\text{m}$).

## Task 5: Mathematical Audit of Batched GAT Graph Construction

### 5.1 Formulation Check ($B > 1, T > 1, J = 25$)
- **Input Dimensions:** Batch size $B$, sequence length $T$, number of joints $J = 25$, feature dimension $C = 3$.
- **Graph Topology:** Spatial graph has $V = 25$ nodes and $E = 48$ directed edges (24 anatomical undirected pairs doubled for bidirectional message passing).

### 5.2 Batched Edge Index Derivation
In `src/graph.py` ([L87-L97](file:///e:/INTERNSHIP%20COE/src/graph.py#L87-L97)):
```python
def build_batched_edge_index(edge_index: torch.Tensor, batch_size_seq_len: int, num_nodes: int = 25) -> torch.Tensor:
    num_edges = edge_index.size(1)  # 48
    offsets = torch.arange(batch_size_seq_len, device=device).repeat_interleave(num_edges)
    batched_edges = edge_index.repeat(1, batch_size_seq_len) + offsets.unsqueeze(0) * num_nodes
    return batched_edges
```
- **Total Flattened Graph Nodes:** $V_{\text{total}} = B \cdot T \cdot 25$.
- **Total Batched Edges:** $E_{\text{total}} = 48 \cdot B \cdot T$.
- **Offset Offset Math:** For graph instance $k \in \{0, \dots, B \cdot T - 1\}$, node index $j \in \{0, \dots, 24\}$ is assigned global index $k \cdot 25 + j$. Edge $(u, v)$ becomes $(u + k \cdot 25, v + k \cdot 25)$.

### 5.3 Attention Mapping Back to Frame and Joint
In `src/model.py` ([L210-L225](file:///e:/INTERNSHIP%20COE/src/model.py#L210-L225)):
```python
dst = edge_index[1] # Destination node global indices (0 to B*T*25 - 1)
node_attention = torch.zeros((batch_size * seq_len * num_nodes,), dtype=edge_attention.dtype, device=edge_attention.device)
node_attention = node_attention.scatter_add(0, dst, edge_attention)
node_attention = node_attention.reshape(batch_size, seq_len, num_nodes)
joint_attention = node_attention.mean(dim=1) # (batch_size, 25)
```
- **Mathematical Validity:** `scatter_add` accumulates incoming edge attention weights at destination nodes $v_{\text{global}}$. Reshaping to $(B, T, 25)$ correctly isolates spatial joint $j$ at frame $t$ for batch sample $b$. `mean(dim=1)` computes average spatial attention over time. **The mathematical logic is exact and sound.**

## Task 9: Mathematical Audit of Epistemic Uncertainty Claim

### 9.1 Formulation in Code
In `src/uncertainty.py` ([L20-L28](file:///e:/INTERNSHIP%20COE/src/uncertainty.py#L20-L28)):
```python
pred_class = int(np.argmax(probabilities))
confidence = float(probabilities[pred_class])
uncertainty = 1.0 - confidence
```
In `results/validation/baseline_drift_validation.md` ([L13](file:///e:/INTERNSHIP%20COE/results/validation/baseline_drift_validation.md#L13)):
> "Epistemic uncertainty must be less than 0.15 ($U < 0.15$)."

### 9.2 Mathematical Audit & Mislabeling Proof
- **Mathematical Fact:** $U = 1.0 - \max_c P(Y=c|X)$ is the **predictive residual / confidence error** of a single deterministic point estimate.
- **Definition of Epistemic Uncertainty:** Epistemic uncertainty measures model parameter ignorance $\text{Var}_{\theta}[P(Y|X, \theta)]$, which requires sampling over the model weight posterior $p(\theta|\mathcal{D})$ (e.g., via Monte Carlo Dropout variance over $N$ forward passes, Ensembles, or Bayesian Neural Networks).
- **Audit Verdict:** Claiming that $1 - \max(\text{softmax})$ represents epistemic uncertainty is **mathematically incorrect and scientific misrepresentation**.
