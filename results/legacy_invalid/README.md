## Scientific Provenance Notice
An exhaustive repository audit confirmed that the reported historical ST-GAT evaluation metric (Accuracy = 85.48%, Macro F1 = 0.8000) was generated by taking a single fold checkpoint (est_model.pt / old_307.pt) trained on 29 subjects and evaluating it across the complete 30-subject dataset (2,589 samples). Thus, 29 of the 30 subjects evaluated were present in the model\'s training set, invalidating generalizability claims.

Furthermore, baseline comparison tables in these historical files compared this training-set evaluation of ST-GAT against true out-of-fold predictions for baseline models.

These files are preserved strictly for provenance, historical transparency, and scientific audit tracking. All valid publication metrics are located under 
esults/final/.
